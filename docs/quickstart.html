第一个绳驱模型¶

本教程使用一个定滑轮和自由物块。物块是 freejoint，不是预先限制在竖直导轨上的 slide；收绳后它只受到重力、绳力和可能的刚体接触力。

1. 下载并放置模型¶

下载完整最小 surface 模型，放到仓库根目录。这个模型只用基本几何，不需要外部 STL。

<mujoco model="mujocable_minimal_surface">
  <compiler angle="radian"/>
  <size nuser_site="1"/>
  <option timestep="0.0005" integrator="implicitfast"/>
  <extension><plugin plugin="mujoco.cable.unilateral">
    <instance name="rope">
      <config key="route_mode" value="surface"/>
      <config key="route_tendon" value="seed"/>
      <config key="wrap_geoms" value="pulley_wrap"/>
      <config key="home_length" value="auto_initial"/>
      <config key="stiffness" value="2000"/>
      <config key="damping" value="5"/>
      <config key="pretension_offset" value="0.000981"/>
      <config key="ctrl_mode" value="target_contraction"/>
      <config key="max_tension" value="20"/>
      <config key="visual_width" value="3"/>
    </instance>
  </plugin></extension>
  <worldbody>
    <light pos="0 -1 2"/>
    <camera name="overview" pos="0 -1.3 0.5" xyaxes="1 0 0 0 0 1"/>
    <geom type="plane" size="0.6 0.6 0.01" rgba="0.2 0.22 0.24 1"/>
    <geom name="pulley_wrap" type="cylinder" pos="0 0 0.6"
          euler="1.57079632679 0 0" size="0.1 0.02" rgba="0.75 0.77 0.8 0.55"/>

先明确四个对象：start 是固定端，hint 选择圆柱上方的绕行侧，end 固定在物块上，pulley_wrap 是真实绳路的障碍面。hint 在初始化后不再是绳长或受力节点。

2. 手动收绳¶

# macOS；Linux 将 mjpython 改为 python、dylib 改为 so。
mjpython scripts/view_cpp_plugin_demo.py \
  --plugin build/plugin/libcable_unilateral.dylib \
  --model minimal_surface.xml \
  --no-auto-control --show-cable-state --duration 120

在右侧 Control 面板调整 pull：

输入

含义

0

不额外收绳；仍有模型设定的预紧

0.010

自由长度目标比原来短 10 mm

0.030

收绳 30 mm；不是施加 0.03 N，也不是强制物块移动 30 mm

控制量 c 是收缩量，正数使自由长度变短。当前几何长度 L、自由长度 L_f 和拉力 T 是不同的量，物块实际运动由动力学决定。

3. 自动演示¶

mjpython scripts/view_cpp_plugin_demo.py \
  --plugin build/plugin/libcable_unilateral.dylib \
  --model minimal_surface.xml \
  --auto-actuator pull --ctrl-final 0.030 \
  --ctrl-ramp-start 0.5 --ctrl-ramp-end 2.5 \
  --show-cable-state --duration 120

先关闭自动输入再用鼠标调滑块。否则自动控制器会在下一步覆盖你的值，看起来就像滑块“失效”。

4. 为什么 gear 是零¶

<actuator>
  <plugin name="pull" instance="rope" tendon="seed"
          gear="0" ctrllimited="true" ctrlrange="-0.02 0.06"/>
</actuator>
<sensor><plugin name="rope_state" instance="rope"/></sensor>

surface 模式由插件直接将表面节点的绳力写入刚体广义力。如果 transmission 再沿原生 seed tendon 施力，会重复加载。因此必须 gear="0"。它不表示“没有驱动”：控制仍进入插件，受力经 passive 阶段施加。

5. 改成被动绳或 native¶

  • 最小被动模型：不含 actuator；用鼠标扰动物块，观察伸长受拉与恢复。刚度有限，不是刚性长度约束。

  • 最小 native 模型：使用原生两点路线和插件单边本构，actuator 使用正常 tendon transmission，不要照搬 surface 的零 gear。

这三份 XML 都经过加载和短时动力学检查。接下来阅读 MJCF 结构 和 驱动。
