计算与物理模型¶

一步仿真的顺序¶

  1. MuJoCo 从当前 \(q,v\) 更新刚体位姿与速度。

  2. MuJoCable 按初始化路线更新自由段、表面接触段和切点。

  3. 由路径计算 L、几何长度率、有效伸长与源端拉力。

  4. 沿局部转角传播分段张力。

  5. 合成节点力，向所属刚体施加广义力。

  6. MuJoCo 结合接触、关节和其他输入积分；sensor 与可视化报告同一物理路径。

路径问题¶

理想化目标是在给定路线类内最小化无穿透路径长度：

\[\gamma^*(q)=\operatorname*{argmin}_{\gamma\in\Gamma(q,\mathcal H)} L(\gamma,q),\qquad L(q)=\sum_i\|x_{i+1}-x_i\|.\]

\(\mathcal H\) 来自 hint 指定的路线类。实际实现是暖启动、局部走廊与迭代优化，不是任意非凸场景的全局最优证明。圆柱侧面可在 \((r\theta,z)\) 展开；mesh 使用三角面走廊、跨边参数与活动接触处理。近相切多表面需联合处理出口/入口和退化自由段。

单边本构¶

当 \(e\le0\) 时不产生推力。对平滑宽度 a，使用

\[\psi_a(e)=\begin{cases}0&e\le0,\\e^2/(2a)&0
\[T=\operatorname{clip}_{[0,T_{\max}]}\left(k\psi_a(e)+d\eta_a(e)\dot L\right), \quad\eta_a(e)=\operatorname{clip}_{[0,1]}(e/a).\]

a=0 时使用未平滑的线性伸长与阻尼门控。taut_hysteresis 引入进入受拉状态的滞回门限，但仍禁止 \(e\le0\) 时推压。

重要

这是当前代码的本构：阻尼项使用几何长度率 Ldot。当自由长度也随收绳改变时，完整伸长率一般是 Ldot - Lf_dot，两者不能直接等同。当前记录的收缩速率还用于速度定向摩擦，不表示阻尼项已自动改成完整材料应变率模型。

max_tension 约束源端本构 T。反向摩擦传播后某一段张力可能更高；不要将它当作所有分段的断裂保护或自动断绳模型。

节点力与虚功¶

令 \(\hat t_i=(x_{i+1}-x_i)/\|x_{i+1}-x_i\|\)，节点力为

\[f_i=-T_{i-1}\hat t_{i-1}+T_i\hat t_i.\]

端点只保留相邻一项。无摩擦时分段等张力，平滑且充分收敛的局部路径应满足虚功关系

\[Q_c\approx-T\frac{\partial L}{\partial q}.\]

实际应在 MuJoCo 的切空间中扰动姿态，使用中心差分并保持路线分支。比较的是每个自由度上的广义力，不是把所有 N 和 N m 直接混成一个无量纲误差。

新版将同一刚体上的接触节点合成为一组力与力矩，再调用 mj_applyFT。这改变计算组织，不应改变物理映射；浮点累加顺序可能产生小差别。

长度率¶

在局部最优路线与固定活动集假设下，可用包络定理避免直接差分接触点滑动参数。离散节点速度来自所属刚体。实现仍受路线残差、三角化和弧段离散影响；特别是已有圆柱离散长度率在某些整体刚体运动中存在微小一致性误差，不能把所有路径后端称为处处解析精确。

三种积分配置¶

integration_mode

作用

使用边界

explicit

默认本构力直接加入动力学

先用这个做标定和步长检查

local_implicit

基于有效质量与上一步张力的局部修正

不是接触/多绳统一隐式求解；当前拒绝 Capstan/guide 摩擦组合

implicit_compliant

试图向宿主注册柔顺绳隐式算子

需要对应的修改版 MuJoCo 内核接口；不是官方 3.4.0 的通用独立插件能力

局部修正使用 \(w=G M^{-1}G^T\)、\(\beta=h d_{eff}+h^2k_{eff}\)：

\[T_{local}=\frac{T_{raw}+\beta w T_{prev}}{1+\beta w}.\]

它只描述当前局部实现，不是非线性接触问题的全隐式解。仅把 MuJoCo integrator 改成 implicitfast，不会自动把任意插件力的导数交给内核。详见接口与架构。
