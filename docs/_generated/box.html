圆角长方体滑轮¶

以圆角处理理想尖角处不唯一的切线。

机构分组： 不规则曲面展示。本页模型资源固定到公开提交 fccad906。

带数字视频 · Raw 视频

下载与源文件¶

模型与完整依赖 ZIP · 数据/图表 ZIP · 单个 XML · GitHub 源文件

ZIP 保留相对路径；解压到独立目录，不要把它误当成包含 MuJoCo 的独立应用。单个 XML 仍可能需要 mesh。

如何驱动¶

mjpython scripts/view_cpp_plugin_demo.py \
  --plugin build/plugin/libcable_unilateral.dylib \
  --model examples/showcase/models/irregular_pulley_box.xml --no-auto-control --show-cable-state

macOS 使用 mjpython；Linux 使用 python，库后缀改为 .so。论文入口默认关闭自动控制，用 Control 滑块手动输入。

实际 actuator 名称： pulley_drive。单位与通道类型请结合 XML 的 actuator 类型和 ctrl_mode，不要一律按 N 或 deg 输入。

自动实验：仓库根目录运行 python examples/paper/run.py result1 --skip-videos 或 result2 --skip-videos。校准双向周期使用 cycle；曲面展示的自动控制命令见 examples/showcase/README.md。

解释与限制¶

圆角是几何假设的一部分，不应称为数学上完全尖角的长方体。

历史视频不冒称最新版重新录制。下载结果包含原始统计，保留偏差和失败诊断；不要只截取最好的一帧作为完整验证。
