源码与发行¶

  • 公开源码仓库：安装、编译、测试、examples 与许可证。

  • GitHub Releases：检查某次发行是否提供你的 OS/架构/MuJoCo ABI 对应资产；不要把源代码 ZIP 当作预编译插件。

  • examples/paper：论文相关冻结模型、统计与复跑入口。

  • examples/showcase：不规则轮和字母曲面示例。

源码和案例包保留 Apache-2.0、Faive 等来源说明。第三方模型的原始许可与署名条件见仓库 examples/paper/ASSET_SOURCES.md，不要把所有外部资产都重新声明成自己的原创。
